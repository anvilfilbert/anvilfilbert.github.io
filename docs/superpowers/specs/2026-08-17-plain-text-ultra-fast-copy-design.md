# MacPad family positioning

## Goal

Present MacPad and MacPad Mobile consistently as ultra-fast native plain-text
editors without expanding or weakening their verified product claims.

## Approved slogan

> Plain text. Ultra fast. No bloat.

## Copy map

- Website hero uses the approved slogan verbatim.
- Website metadata describes both apps as ultra-fast native plain-text editors
  for their supported Apple platforms.
- MacPad GitHub description: `Ultra-fast native plain-text editor for macOS.
  No bloat.`
- MacPad Mobile GitHub description: `Ultra-fast native plain-text editor for
  iPhone and iPad. No bloat.`
- Each README opening uses its repository description as the first product
  sentence.
- Product sections and website footer reinforce plain text and native speed
  without repeating the full slogan unnecessarily.

## Boundaries

- Preserve platform requirements, availability warnings, privacy statements,
  feature details, download links, and installation instructions.
- Do not publish numerical performance claims without benchmark evidence.
- Do not imply synchronization between the independent applications.

## Verification

- Run the website validator.
- Run whitespace and link checks for every changed repository.
- Verify both GitHub repository descriptions after updating them.
- Verify the deployed website contains the approved slogan.
