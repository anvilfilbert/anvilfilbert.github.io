01 / macOS 14+

MacPad

An ultra-fast native macOS plain-text editor modeled after the directness of classic Notepad, with modern tabs, windows, session restore, encoding awareness, and the controls a real desktop needs.

  • Multiple windows and tab groups
  • Find, Replace, Go to Line, and Open Recent
  • Encoding and line-ending preservation
  • Universal Apple silicon and Intel build

02 / iOS + iPadOS 18+

MacPad Mobile

Ultra-fast native plain-text editing for iPhone and iPad with compact tabs, Apple Files integration, explicit Save, conflict protection, and deliberate device-local recovery.

  • One focused workspace with multiple document tabs
  • Direct Apple Files editing when access is durable
  • Protected Save As flow for detached or read-only content
  • No account, analytics, advertising, or app network client
Available from source. TestFlight and App Store distribution are not available yet.

Shared files, separate workspaces

Related, not entangled.

MacPad and MacPad Mobile are independent native apps. They do not synchronize tabs, settings, or recovery data. Put a plain-text file in a shared location you control, then open it explicitly from either app.
